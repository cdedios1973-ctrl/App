Project AppInfraestructure

The test of this assembly is to have a collection of small tools to use with Logic and DAO.

CORE Folder
	- Interfaces folder : Internal interfaces definitions.
	- XMLReader folder  : Read internal application configuration files.

Services Folder
	- ConnectionStringService : Obtain the connection string of the database from AppInfraestructure.config.
	- DataBaseLocationService : (WIP) Obtain the fixed location database from AppInfraestructure.config.

Installation Folder (this will be removed)
	- To test the deployment of the Database with Tables, records and relations.
