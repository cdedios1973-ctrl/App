### Engineered for Maximum Throughput
This ERP framework is built for ultra-low memory footprints and high-speed data access. By leveraging native ADO.NET and pure, parameterized SQL/T-SQL, it ensures predictable, maximum performance and optimal query execution speeds under heavy workloads.

## 🛠️ Tech Stack & Architecture

*   **Language & Runtime:** C# / .NET 9.
*   **Architecture:** Clean Architecture approach (Domain, Application, Infrastructure, Presentation) ensuring decoupled, testable, and maintainable code.
*   **Data Access Layer:** High-speed native ADO.NET and optimized SQL/T-SQL for raw performance and direct database control.
*   **Presentation Layer:** Modernized WinForms desktop UI running on .NET 9, optimized for rapid data entry and high-density enterprise layouts.
