### Engineered for Maximum Throughput

As part of this learning process, I focused on achieving ultra-low memory footprints and high-speed data access. 
By leveraging native ADO.NET and pure, parameterized SQL/T-SQL, I am testing how to get predictable performance and optimal query execution speeds under heavy workloads.

---

## 🛠️ Tech Stack & Architecture

* **Language & Runtime:** C# / .NET 9.
* **Architecture: Clean Architecture approach (Domain, Application, Infrastructure, Presentation) to practice building decoupled, testable, and maintainable code.
* **Data Access Layer: High-speed native ADO.NET and optimized SQL/T-SQL for raw performance and direct database control.
* **Presentation Layer: Modernized WinForms desktop UI running on .NET 9, designed for rapid data entry and high-density enterprise layouts.


```text
1. Domain         # Core enterprise business logic and models.
2. Application    # Use Cases and application logic.
3. Infrastructure # High-speed native ADO.NET and Sqlite.
4. Presentation   # The WinForms user interface.
```
